# Baseline A Contextual Safety Assessment

This is a pilot assessment, not a safety certification or a claim about a
built product. `safety.tsv` records baseline-bound assertions rather than
intrinsic requirement attributes.

The project-defined `PILOT-MONITORING-CONSEQUENCE-1` scheme means:

- `L0`: no identified contribution to the monitoring-related operational
  hazard in the assessed context;
- `L1`: loss or error impairs oversight, investigation, or recovery while an
  independent local safeguard remains; and
- `L2`: loss or misleading behavior can directly contribute to an unrecognized
  excursion or an unsupported vaccine-disposition decision.

The level is a judgment over a requirement revision, context, scheme, and
rationale. It is not an immutable property of the requirement. The table
selects only consequential requirements; omission means not assessed here, not
`L0`.
