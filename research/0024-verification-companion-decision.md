# Verification Companion Model Decision

Status: Conceptual model selected; syntax provisional

Date: 2026-08-29

[Experiment 0017](../experiments/0017-verification-evidence/README.md) exercises
activities, exact baseline-bound coverage, executions, evidence locators, and
results as separate human-readable source artifacts.

Retain that separation. Planned, executed, evidenced, passing, and uncovered are
distinct states. Activity identity and definition belong to the activity;
coverage belongs to a plan over an exact requirement baseline; configuration
belongs to an execution; evidence location and integrity belong to an evidence
reference; outcome and basis belong to a result. None is an intrinsic scalar on
a requirement.

The TSV carrier is not a stable language. Before standardizing syntax, exercise
the model through another verification workflow and a narrow analyzer. Git may
version and review these facts, but Git does not establish their technical
validity, evidence authenticity, or certification meaning.
