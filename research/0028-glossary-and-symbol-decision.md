# Glossary and Formal-Symbol Decision

Status: Companion artifacts deferred

Date: 2026-08-29

[Experiment 0021](../experiments/0021-glossary-symbols/README.md) separates a
domain-term rename from a definition-only meaning change and derives the same
three affected requirements in each workflow. Stable identity and explicit use
mappings work, but authoritative prose plus ordinary source search finds the
same set with less maintenance in this bounded corpus. That does not satisfy
the adoption gate. Tool-owned vocabulary requires code changes for both rename
and meaning revisions.

Normativity is independent of representation: prose or a structured artifact
can be authoritative or advisory by project declaration. Use ordinary prose
for guidance and simple definitions. Revisit the companion candidate only when
a larger workflow makes continuity or impact ambiguous enough that search is
insufficient.

Do not select a formal-symbol companion from this evidence. The existing UAS
formula stays complete with adjacent symbol definitions and units, while two
local equation scopes legitimately give `T` different meanings. LaTeX remains
opaque. No `.mreq` syntax or companion carrier is standardized.
